# 청감 품질 검토 — 2026-09-29

사용자 피드백: 다른 Curve Lab보다 소리가 싸구려스럽고 음향적 매력이 부족하다. 이는 제품 품질 이슈이며 기존 수치 테스트의 통과로 해소되지 않는다. 이번 기록은 코드·보고서를 근거로 한 **원인 가설과 검증 순서**다. 실제 입력·설정·출력 경로·모니터링 환경은 미확인이고, DSP를 아직 변경하지 않았다.

## 확인된 설계 요인

1. 기본 소스는 8초간 짧은 백색소음 구간을 반복한다(`app.js:createGeneratedExampleBuffer`). 주기성·배음 진행·지속적 제스처가 거의 없어 Stretch/Shift의 음악적 관계를 평가하기 어렵고, Blur는 noise attack을 약하게 만드는 쪽으로 들릴 수 있다. 이는 **데모 소스의 한계**이며 DSP 결함 증거는 아니다.
2. Shift는 배음마다 같은 Hz를 더한다. 예를 들어 440/880Hz에 +200Hz를 주면 640/1080Hz로, 새 기본음 640Hz의 2배(1280Hz)가 아니다. 금속성/비화성은 일부가 효과의 본질이다. ±2000Hz UI 전 범위를 음악적으로 유효하다고 승인한 기록은 없다.
3. Stretch는 peak-region 추정/이동과 분수 bin 보간으로 배음 간격을 비선형 변화시킨다. 기존 단음 검사에서도 최대 약 3% 진폭 감소가 있고, 복잡음/어택의 청감 평가는 미완료다. 고정 1kHz pivot과 0.5–2.0 범위도 청감 sweet spot이 아니라 현재 수치 계약이다.
4. Blur는 `0.5×amount²`초의 시간 평활을 쓰며 100%는 500ms 상수다. 어택의 존재감을 줄이고 이전 성분을 남긴다. 위상 진행 추정의 복잡음 아티팩트는 기존 보고서도 한계로 표시했다.
5. 세 효과는 순서대로 모두 wet 처리된다. 사용자에게 원음과의 혼합량이나 transient 보호가 없다. Preview 2048/Render 4096 FFT 차이와 WAV 출력의 무 limiter/clipping 가능성도 품질 비교를 어렵게 한다.

## 검증 후 개선 후보 — 미승인 제안

**1차 진단:** 같은 실제 음원에서 neutral output을 source와 레벨 매칭해 듣고, 세 효과를 하나씩 작은 값부터 A/B한다. 어택/지속음/무음 꼬리, 스테레오, Preview/WAV를 분리한다. 기본 데모에는 음정과 시간 변화가 있는 짧은 악기 음원을 추가하거나 기존 noise를 진단 예제로 명시하는 방안을 평가한다. 원음이 neutral에서 이미 손상되면 효과보다 STFT/출력 경로를 먼저 고친다.

**2차 음질:** transient 검출 후 어택 구간의 위상을 유지하거나 처리량을 낮추는 실험, Stretch peak 추적·phase coherence 개선, Blur의 attack 보존/짧은 유효 시간 범위, 작은 Shift 중심의 민감도 재설계를 서로 독립적인 A/B로 비교한다. 원음 혼합량(Mix)은 효율적인 후보지만 새 파라미터이므로 범위·보간·상태·Preview/Render 계약과 청감 테스트 후에만 제품화한다. 단순 출력 증폭으로 음색 문제를 가리지 않는다.

**결정 기준:** 각 개선은 입력/곡선/출력 경로/레벨/모니터 환경/청감 차이/아티팩트/CPU/Preview·Render 비교를 기록한다. 청취 결과가 없으므로 우선순위는 가설이며, 현재 세 효과의 숫자·DSP는 변경하지 않았다.

재현 자료의 확보 상태와 A/B 기록 절차는 [Reference Sound Set](REFERENCE_SOUND_SET.md), 실제 채택·기각·보류 판정은 [청취 판단 기록](LISTENING_DECISIONS.md)에 남긴다.
