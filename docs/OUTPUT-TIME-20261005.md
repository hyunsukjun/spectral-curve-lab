# OUTPUT TIME 탐색창 — 2026-10-05

## 결정과 보존 범위

커브창의 원본 파형을 96px 탐색 Canvas로 분리하고 Position 슬라이더와 커브창 double-click seek를 제거했다. 파형과 재생 바는 같은 하단 dock에 둔다. 커브/체인과 탐색창을 노트북 첫 화면에서 사용할 수 있도록 커브의 최소 표시 높이를 240px로 정했다. 분석 패널은 축소하지 않고 세로 스크롤로 접근한다.

OUTPUT TIME은 동일 길이의 탐색 시간축이며 최종 WAV 파형이 아니다. 원본 입력 채널별 peak를 한 번 계산하고 정적 배경을 캐시한다. 모노 한 줄, 스테레오 L/R 두 줄을 표시한다. 실제 Preview 출력의 L/R 미터와 의미가 다르다. Curve Canvas와 동일한 좌우 여백 54px/8px를 사용한다. Spectral Stretch는 주파수 간격 변형이며 파일 길이에 영향을 주지 않는다.

현재 위치는 밝은 1.5px 실선과 위/아래 삼각형, hover는 같은 색·굵기의 점선이다. 드래그와 포인터 이탈 중 hover를 숨긴다. hover는 탐색 Canvas만 갱신한다. 키보드 방향키는 1초, Shift+방향키는 0.1초, Home/End는 처음/끝이며 role=slider, 현재 초/전체 길이를 제공한다.

기존 seek 메시지·token·드래그 중 위치 보고 무시 경로를 재사용한다. 엔진 생성 전에 선택한 위치는 첫 Play의 초기화 뒤에 전달한다. 이 UI 연결 외에 Worklet, FFT/STFT, Freeze/Blur 상태 초기화, 효과 체인·커브 보간·렌더 엔진은 변경하지 않았다. seek/hover는 스펙트로그램이나 전체 렌더를 새로 요청하지 않는다.

## 검증

로컬 Chrome 자동 브라우저 검사:

- 정지 상태 첫 seek 후 최초 Play가 4초에서 시작. 일시정지 seek 및 재개, 재생 중 드래그, Stop 후 0초 확인.
- 방향키/Shift+방향키/Home/End와 접근성 현재 값 확인.
- Blur/Freeze에 중립이 아닌 점을 넣고 Shift 순서 재배치 후 드래그. 위치 보고가 이전 위치로 돌아오지 않고 커브 점 개수 유지.
- 화면 픽셀 검사로 임시 점선, 현재 실선, leave/drag 중 임시선 해제 확인.
- 비교 분석 완료 후 hover/seek를 수행해 Worker 요청 수가 증가하지 않고 비교 완료 상태 유지.
- 180초 모노 WAV와 2초 스테레오 WAV 입력, 채널 수 표시와 90%/끝 위치 확인.
- 1366×768, 1280×800, 1280×600, 390×700, 1920×1080에서 두 Canvas의 x/폭 정렬과 페이지 가로 넘침 없음 확인.
- 다섯 효과 활성화 시 1366×768/1280×800에서 체인 하단이 dock 상단보다 각각 약 4px/16px 위. 분석 패널을 펼친 후 스크롤 끝에서 마지막 항목이 dock 위로 약 38px 여유를 두고 노출.
- 실제 WAV 다운로드: 576,044 bytes, 2초 스테레오 PCM24/48kHz. 브라우저 page error 없음.
- JavaScript 문법 검사, 기존 transport 128개 조합 및 Harmonicity/Freeze seek-reset 수치 검사 통과.

청감/물리 출력과 Safari·실제 터치 장치는 미검증이다. 기존 hard seek의 준비 무음이나 click 가능성은 해결했다고 주장하지 않는다. 지속적인 seek에 따른 음질/지연은 별도 청취 검토 대상이다. 커밋·공개 배포는 수행하지 않았다.
